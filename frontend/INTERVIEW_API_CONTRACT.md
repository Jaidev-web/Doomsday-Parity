# TrustHire Interview & Proctoring API Contract

This document specifies the exact FastAPI backend endpoints expected by the frontend interview system (`Doomsday-Parity`).

---

## 1. Architecture Overview

```
Frontend Candidate Room (/candidate/interview)
   │
   ├── [Mic Audio] ──> POST /api/interviews/{sessionId}/audio ──> Local Whisper STT
   │
   └── [Webcam Feed] ──> WebRTC / Frame Telemetry ──> OpenCV / Gaze Tracking

Frontend HR Monitoring Center (/dashboard/candidates/{id}/interview)
   │
   ├── [Resume Scanned] ──> POST /api/interviews/{sessionId}/questions/from-resume ──> Ollama + Gemma 4
   │
   ├── [Spoken Answer] ──> POST /api/interviews/{sessionId}/analyze-response ──> LangChain / AI Detector
   │
   └── [Proctoring Logs] ──> POST /api/interviews/{sessionId}/events ──> Session Audit DB
```

---

## 2. Endpoints Specification

### A. Session Management
- **`POST /api/interviews/sessions?candidate_id={candidateId}`**
  - Starts interview session.
  - Response: `{ "session_id": "session-123", "candidate_id": "cand-sarah-001", "started_at": "ISO", "status": "active" }`

- **`POST /api/interviews/{sessionId}/complete`**
  - Concludes interview and generates final integrity score.
  - Body: `{ "summary": "...", "integrity_score": 88, "qa_count": 5 }`

---

### B. Whisper Speech-to-Text Transcription
- **`POST /api/interviews/{sessionId}/audio`**
  - Receives spoken answer from candidate's microphone.
  - Content-Type: `multipart/form-data`
  - Form Fields:
    - `audio`: WebM / Opus audio blob
    - `question_id`: string
  - Processed using: **Local Whisper** (`whisper-base.en` or `faster-whisper`).
  - Response:
    ```json
    {
      "transcript_id": "tr-456",
      "transcript_text": "React reconciliation utilizes virtual DOM diffing...",
      "duration_seconds": 24.5,
      "confidence": 0.96
    }
    ```

---

### C. Gemma & LangChain Question Generation
- **`POST /api/interviews/{sessionId}/questions/from-resume`**
  - Generates technical questions probing resume claims.
  - Body:
    ```json
    {
      "skill": "React",
      "project": "Micro-frontend migration",
      "context": "Senior Frontend Engineer at TechFlow"
    }
    ```
  - Backend uses: **Local Ollama with Gemma 4** + LangChain context chain.
  - Response:
    ```json
    [
      {
        "question_id": "q-react-01",
        "question_text": "Walk me through how React reconciliation works. How does the virtual DOM diffing algorithm decide what to re-render?",
        "difficulty": "medium",
        "category": "technical"
      }
    ]
    ```

---

### D. AI-Generated Answer Detection
- **`POST /api/interviews/{sessionId}/analyze-response`**
  - Evaluates whether candidate's spoken response was generated by an LLM (e.g. ChatGPT / Claude).
  - Body:
    ```json
    {
      "transcript": "In order to optimize distributed system architecture...",
      "question_id": "q-01"
    }
    ```
  - Analyzes:
    1. Perplexity & vocabulary complexity
    2. Filler word density (absence of natural conversational hesitation)
    3. Sentence syntactic uniformity
  - Response:
    ```json
    {
      "ai_score": 88,
      "signals": {
        "vocabulary": "Artificially elevated textbook prose",
        "fillers": "0 fillers detected (Unnatural fluency)",
        "uniformity": "Uniform syntactic length matching GPT-4 output"
      },
      "verdict": "likely_ai"
    }
    ```

---

### E. Background Integrity Telemetry & Eye Gaze
- **`POST /api/interviews/{sessionId}/events`**
  - Body:
    ```json
    {
      "event_type": "tab_switch | gaze_away | window_blur | large_paste",
      "severity": "low | medium | high | critical",
      "timestamp": "2026-11-13T12:00:00Z",
      "metadata": { "count": 3 }
    }
    ```
